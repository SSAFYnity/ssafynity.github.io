# SSAFYnity 공식 홈페이지 디자인 시스템

이 문서는 `ssafynity.github.io` 저장소 안에서 완결되는 공식 홈페이지 디자인 기준이다. 외부 작업공간 문서나 다른 저장소를 빌드 의존성으로 사용하지 않는다.

## 제품 역할

| 항목 | 기준 |
| --- | --- |
| 배포 URL | `https://ssafynity.github.io/` |
| 방문자 모드 | Persuade + Operate |
| 주요 목적 | 동문회 이해, 행사 확인, 가입과 참여 |
| 핵심 증거 | 행사 일정, 운영 기록, 동아리, 회원과 운영진 데이터 |

## 디자인 명제

> 운영되는 동문회를 실제 정보와 행동으로 보여준다.

장식적인 커뮤니티 이미지를 만드는 대신 방문자가 다음 행사, 최근 공지, 참여 방법을 빠르게 판단하도록 한다.

## 사용 규칙

- 파란색은 브랜드와 행동에만 사용한다.
- 카드에는 독립 행동이나 정보 단위가 있어야 한다.
- 단순 목록과 통계는 여백과 구분선으로 구성한다.
- 상태와 짧은 분류에만 pill을 사용한다.
- 제목 위의 장식용 영문 eyebrow를 사용하지 않는다.
- border와 shadow를 같은 요소에 중복하지 않는다.
- 실제 행사 사진과 포스터가 있으면 추상 아이콘보다 우선한다.
- `prefers-reduced-motion`과 키보드 포커스를 기본 지원한다.

## 금지 패턴

- 떠 있는 다색 아이콘 타일 히어로
- 동일한 `아이콘 + 제목 + 설명` 카드 반복
- gradient text와 장식용 blur
- 콘텐츠를 대신하는 자동 마키
- 다른 저장소나 상위 작업공간을 참조하는 import와 정적 자산 경로

## 독립성

- 이 저장소만 clone한 상태에서 설치, 빌드, 배포할 수 있어야 한다.
- 블로그의 CSS, 컴포넌트, 문서를 import하지 않는다.
- 공통 브랜드 값의 변경은 이 저장소 안에서 명시적으로 반영하고 검증한다.

## 공통 셸 적용

| 대상 | 구현 기준 |
| --- | --- |
| Header | `76px` 평면형 헤더, 텍스트 내비게이션, 현재 위치 밑줄, 블로그 전환 링크 |
| Dropdown | `14px` 패널, 단일 border, 키보드·Escape 지원 |
| Mobile menu | 우측 독립 패널, `44px` 조작 영역, 스크롤 잠금과 복원 |
| Footer | Brand navy 역상 배경, 전체 메뉴, 소셜 채널, 블로그 전환 링크 |

구현 파일은 `src/components/Navbar.astro`, `src/components/Footer.astro`다. 블로그 컴포넌트나 스타일을 import하지 않는다.

## 홈 적용

| 영역 | 기준 |
| --- | --- |
| 첫 화면 | 동문회 정의, 가입 행동, 실제 예정 행사 |
| 운영 현황 | 회원·기수·행사·운영 연수를 구분선 구조로 표시 |
| 참여 | 가입·정회원·동아리 경로를 순차 행동이 아닌 독립 선택지로 제공 |
| 기록 | 실제 행사 이미지와 데이터로 최근 행사를 연결 |
| 파트너 | 자동 마키 없이 공식 파트너 관계를 한 줄 구조로 표시 |

구현 파일은 `src/pages/index.astro`다. 추상 아이콘 히어로와 반복 기능 카드는 사용하지 않는다.

Hero는 `src/components/HomeHero.astro`에서 독립 구현한다. 블로그와 `1180px` 콘텐츠 폭, 제목 스케일, 2열 비율, CTA, `16px` 밝은 브랜드 틴트 패널, 모바일 재배치 규칙을 동일하게 유지하고 예정 행사 데이터만 공홈 역할에 맞게 표시한다.

## 행사 적용

| 영역 | 기준 |
| --- | --- |
| 연간 일정 | 월·일·상태·제목·장소를 구분선 일정표로 표시 |
| 역대 행사 | 검색·다중 필터·페이지 이동을 유지하고 카드뷰와 목록뷰를 선택 가능하게 제공 |
| 행사 상세 | 실제 이미지, 일시, 접수 기간, 장소, 진행 방식과 신청 상태를 우선 표시 |
| 상세 탭 | 행사 안내, 비용·환불, 접수 현황, 참여 결과, 관련 기록 기능 유지 |

구현 파일은 `src/pages/events/upcoming/index.astro`, `src/pages/events/archive/index.astro`, `src/pages/events/archive/[slug].astro`다. 기존 행사 데이터와 상태 계산, 필터, 갤러리, 신청 기능을 유지한다. 접수일·행사 시각에서 계산한 상태 라벨은 카드뷰와 목록뷰에서 동일하게 노출한다.

## 최종 검증

| 항목 | 결과 |
| --- | --- |
| 정적 페이지 | 56개 빌드 완료 |
| HTML 구조 | 페이지별 `h1`·`main` 1개, 이미지 대체 텍스트·중복 ID·이름 없는 버튼·메타데이터 누락 0건 |
| 반응형 | `1440px`, `768px`, `390px` 대표 화면 가로 오버플로 0 |
| 기능 | 모바일 메뉴, 행사 검색·필터, FAQ 페이지 버튼 이름 확인 |
| 소스 검사 | Impeccable 탐지 0건, `git diff --check` 통과 |
| 저장소 검사 | `npm run build`, `npm run verify:migration` 통과 |

홈의 중첩 랜드마크와 404 제목 구조를 정리하고, 모바일 메뉴 항목의 최소 터치 높이를 `44px`로 통일했다. 다른 저장소의 파일을 참조하거나 공유하지 않는다.
